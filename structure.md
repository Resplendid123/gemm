### 一个 SM (Streaming Multiprocessor) 内部:
═══════════════════════════════════════════════════════════════════════════════

                    ┌────────────────────────────────┐
                    │   Warp Scheduler 0             │
                    │   ┌─────┐ ┌─────┐ ┌─────┐      │
                    │   │Warp0│ │Warp1│ │Warp2│ ...  │
                    │   └──┬──┘ └──┬──┘ └──┬──┘      │
                    └──────┼──────┼──────┼───────────┘
                           │      │      │
                    ┌──────┼──────┼──────┼───────────┐
                    │   Warp Scheduler 1             │
                    │   ┌─────┐ ┌─────┐ ┌─────┐      │
                    │   │Warp0│ │Warp1│ │Warp2│ ...  │
                    │   └──┬──┘ └──┬──┘ └──┬──┘      │
                    └──────┼──────┼──────┼───────────┘
                           │      │      │
                           ▼      ▼      ▼
                    ┌─────────────────────────────┐
                    │   CUDA Cores (32 per SM)    │
                    │  ┌────┬────┬────┬────┐      │
                    │  │ C0 │ C1 │ C2 │... │ C31  │
                    │  └────┴────┴────┴────┘      │
                    │   每个周期执行一个 Warp       |
                    └─────────────────────────────┘
                           ↑      ↑      ↑
                           │      │      │
                    ┌─────────────────────────────┐
                    │   Shared Memory (SRAM)      │
                    │   64KB - 164KB per SM       │
                    └─────────────────────────────┘

一个 SM 同时处理多个 Warp
当 Warp 0 等待内存时，调度器立即切换到 Warp 1

### 索引层次
硬件层级           软件抽象           索引变量
═══════════════════════════════════════════════════════════════

GPU Device         Kernel             - (隐式)
    │
    ├─ SM 0         Grid              gridDim (总 Block 数)
    │   │
    │   ├─ Block 0  Block             blockIdx (当前 Block ID)
    │   │   │
    │   │   ├─ Warp 0                 
    │   │   │   ├─ Thread 0           threadIdx.x = 0
    │   │   │   ├─ Thread 1           threadIdx.x = 1
    │   │   │   └─ ...                
    │   │   │
    │   │   ├─ Warp 1                 
    │   │   └─ ...
    │   │
    │   ├─ Block 1  
    │   └─ ...
    │
    ├─ SM 1
    └─ ...

计算公式：
    Global Thread ID (1D) = blockIdx.x × blockDim.x + threadIdx.x
    Global Row (2D) = blockIdx.y × blockDim.y + threadIdx.y
    Global Col (2D) = blockIdx.x × blockDim.x + threadIdx.x
    Warp ID = (threadIdx.y × blockDim.x + threadIdx.x) / 32
    Lane ID = (threadIdx.y × blockDim.x + threadIdx.x) % 32
